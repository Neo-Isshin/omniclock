## macOS 热更新 1 / Hotfix 1 · 2026-11-08

本次只更新 macOS Glass 和 macOS Normal，应用版本保持 v1.0.0。Windows 和 Linux 安装包不变。

- 新增直接读取 Claude App 自身的 OAuth 缓存，复用内置 Code 使用的已有登录查询共享额度，无需额外安装 CLI。
- 核对账号、组织、权限和实际过期时间；登录状态变化时丢弃本轮结果，避免回显旧账号额度。
- 后台只读且不弹授权，不启动 Code 会话、不改写或续期凭据。
- 安装器和版本切换下载按 SHA-256 区分缓存，避免同版本热更新继续下载旧包。

**验证范围：**此前 Glass 81 项、Normal 88 项测试通过，两个真实登录测试因本机没有有效登录而跳过；本次发布前两版各有 33 项热更新下载与额度边界测试通过。真实账号额度读取等待反馈用户验证。

**更新后确认：**“关于”应显示 **v1.0.0 · 热更新 1 / Hotfix 1**。保持 Claude App 原有登录，在 OmniClock 的订阅额度页点击“重试”；成功时来源为“Claude App · 共享订阅额度”。是否需要首次系统授权仍取决于已有钥匙串权限，后台不会主动弹窗。

按所用版本执行 `omniclock update --glass` 或 `omniclock update --normal`；原 `tokenclock` 命令仍兼容。无需退出 Claude、重新登录或安装独立 CLI 来完成更新。

这是同版本热更新，请执行更新命令或重新下载对应安装包；旧版“检查更新”仅比较版本号，可能仍提示已是最新。

This hotfix updates both macOS packages within v1.0.0. It reuses Claude Desktop OAuth credentials for read-only quota queries and keeps account/organization binding, expiry checks and silent background access. Automated tests passed; a live signed-in account is still awaiting reporter validation. Windows and Linux packages are unchanged.
